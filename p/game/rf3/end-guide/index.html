1 刷钱

1.1 前期

  • （1）腌芜菁(料理)
    • 前期狂种樱芜菁，然后做徒手料理腌芜菁，全部卖出，能带来一笔不错的收益

1.2 中期

  • （1）恋爱的预感(料理)
    • 解锁了草莓和少女蜜瓜，可以边刷作物等级，边制作搅拌机料理恋爱的预感
    • 若已经能做出10级料理，可以直接杂货屋购买材料回家做即可，两种材料还是比较好凑的

  • （2）照烧金枪鱼(料理)
    • 能比较轻松钓起大型鱼后，可以前往钓鱼屋钓金枪鱼，杂货屋购买白萝卜，制作平底锅料理照烧金枪鱼
    • 利润很高，但没法批量制作，制作数量全看钓的金枪鱼数量，无法实现利滚利，但可以作为利滚利的启动资金

1.3 后期

  • （1）什锦火锅(料理)
    • 料理等级达到58级，改为制作锅料理什锦火锅
    • 若已经能做出10级料理，可以直接杂货屋购买材料回家做即可，需要4种材料，可能需要分几天购买才能制作

  • （2）黄金果汁(料理)
    • 解锁了全部黄金作物后，改为制作搅拌机料理黄金果汁
    • 若已经能做出10级料理，可以直接杂货屋购买材料回家做即可，需要5种材料，可能需要分几天购买才能制作

2 刷作物等级

  • 作物种子等级提升可以通过：好种的地 + 枯草(用锄头触地) + 速速绿 + 收获掉落/镰刀收割的方式，一次提升4级
  • 将高等级种子放入出货箱，杂货店或花店种子会刷新成该等级，购买回来然后继续重新种
  • 1级 -> 5级 -> 9级 -> 10级，所以理论上种3轮作物就可以拿到10级种子
  • Tips：金色作物种子和菠萝种子无法在杂货店购买，建议将镰刀收割到的种子直接种，种出10级种子再出货
  • 枯草：出货箱出货过枯草后，可在花店概率刷出购买
  • 速速绿：医院可以直接购买

2.1 好种的地

  • （1）春季：龙玄洞-春日普照石室

  • （2）夏季：龙玄洞-夏龙舞骨石室、索尔·提拉诺沙漠-浴水荒骨（最左侧田地）

  • （3）秋季：龙玄洞-秋时交错石室、奥德华山谷-风纹洞、奥德华山谷-避风港

  • （4）冬季：龙玄洞-冬旅休歇石室、茵瓦艾尔河-止风洞

3 刷技能等级

3.1 前期

  • 锻造，加工：通过反复强化高困难度的素材，来获取高额经验值，推荐强化废铁(强化困难度：62)

  • 调和：做低成功率的高级药品即可，只要成功率不是100%，经验都挺高，药品的材料一般都是花，花店可以直接购买，材料好弄不难刷

  • 料理：刷钱时会制作大量料理，刷钱的同时会顺便把料理等级刷上去，不用特意刷

3.2 后期

  • 农田种满连续收获类作物，靠收获作物随机出现的符文光球，来提升技能等级
    • 符文光球：随机提升一个技能的等级（会随机到已经满级的技能，后期剩一两个技能时比较难提升）

4 刷人物等级

  • 花店购买四叶草(需先出过货，否则花店刷不出)，制药台制作符文药水(需调和等级90级以上)，佩戴星型坠饰后，狂喝符文药水即可

5 毕业装备

  • 后期人物升级带来的属性成长远比装备提供的要高，所以装备更加追求功能性，而非面板
  • 武器优先堆：攻击吸血，攻击状态异常
  • 防具优先堆：满状态异常抗性，满眩晕抗性，满暴击抗性、满吹飞抗性、满即死抗性

5.2 法杖强化知识

  • （1）法杖有3个蓄力等级，强化不同的素材，会有不同的蓄力效果和蓄力速度
  • （2）法杖的蓄力效果新的强化素材会覆盖之前的强化素材，
    • 例如：素材1有蓄力等级123的效果，素材二只有蓄力等级3的效果。如果先强化素材1，后强化素材2，素材2蓄力等级3的效果会覆盖素材1蓄力等级3的效果，蓄力等级12不会覆盖
  • （3）法杖的蓄力速度由最后一个强化素材决定
  • （4）法杖具体强化素材效果查看【符文3日本wiki】

5.4 蓝名装备

  • 在成功率达到100%时制作装备，会制作出蓝名装备，会从符文3的所有强化素材中，随机挑选两个材料进行强化，这两次强化是额外送的
  • 由于3代没有装备鉴定功能，除了部分数值变化比较明显的素材，大部分时候你无法判断强化了什么素材
  • 所以当个添头就好，不太用特定刷极品素材，如果有追求，可以自己通过数值变化，对照素材表，判断强化了什么素材
  • 【符文3日本wiki-素材表】

    • 暴击抗性：128 + 32 - 25 = 135
    • 眩晕抗性：128 + 64 - 25 = 164
    • 吹飞抗性：128 + 64 = 192

  • 通过计算得出的强化素材：
    • 11个坏掉的木箱、10个龟壳、7个优质的毛皮
    • 剩余的素材来堆攻击力（火龙鳞片）就好，不推荐堆防御力
    • 怪攻击玩家达到伤害上限9999所需的等级，远低于玩家攻击怪达到伤害上限所需的等级。即你1000多级，堆满防御力，怪攻击你还是随随便便达到9999，但你攻击怪物并不能打出9999伤害

6 树洞迷宫通关

  • 直到通关一次挑战虚幻之前，都是相对比较简单，带宠物、剑草种子、向boss扔油放火魔法，都是简单通过
  • Tips：装备停战的祈祷进入迷宫，会直接进入boss房，不用清小怪，进入迷宫后就可以切换其他饰品，无需一直携带

  • 一旦通过一次挑战虚幻后，迷宫中怪物等级会同步玩家等级，难度直线上升
  • 这时候要通关的话，推荐抓迷宫同级宠物，玩家装备草原坠饰强化宠物，宠物轻松打出伤害上限9999
  • 抓宠推荐无属性怪物就好，这边推荐高等维京食人魔(飞斧哥)，一斧子9999，轻松击杀boss

7 宠物培养

  • 个人是不推荐花时间培养宠物，因为宠物等级跟不上玩家升级速度，一旦等级落后打不出伤害后，不如重新去迷宫抓一只新的同级宠物好用
  • 宠物强化每天只能喂的一个素材，一天多喂无效，因此培养极品宠物需要花费较长天数
  • 宠物强化没有具体数据支撑，无法给出一个合适的方案，想了解可以看wiki和贴吧大佬总结
